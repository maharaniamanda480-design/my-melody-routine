MY MELODY DAILY ROUTINE WIDGET

Ini adalah proyek sumber aplikasi Android (bukan APK siap pasang).
Fitur:
- Widget homescreen dengan tema pink dan ilustrasi kelinci original.
- 24 tugas rutinitas dari daftar awal, 4 tugas per halaman.
- Centang langsung dari widget.
- Progres 0-100%, tombol reset, navigasi halaman.
- Checklist direset saat widget dibuka/diperbarui setelah tanggal berubah.

Cara membuat APK:
1. Buka proyek ini di Android Studio pada komputer.
2. Tunggu Gradle sync dan unduh Android SDK yang diminta.
3. Pilih Build > Build Bundle(s) / APK(s) > Build APK(s).
4. APK debug akan berada di app/build/outputs/apk/debug/app-debug.apk.
5. Pindahkan APK ke HP Android dan instal. Izinkan instalasi dari sumber tersebut jika Android memintanya.
6. Homescreen > tekan lama area kosong > Widgets > My Melody Daily Routine > tarik ke layar.

Catatan: proyek belum dikompilasi menjadi APK di lingkungan ini karena Android SDK/Gradle tidak tersedia. Nama/tema My Melody bersifat fan-style; ikon kelinci adalah ilustrasi sederhana original, bukan aset resmi Sanrio.
